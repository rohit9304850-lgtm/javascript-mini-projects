# JavaScript Mini Projects

A collection of 9 small projects I built while learning JavaScript and practising frontend development.

Each project helped me understand JavaScript concepts and apply them through practical implementation using HTML, CSS and JavaScript.

## Projects

### 01. Random Quote Generator
Generates random quotes dynamically.

### 02. Background Colour Generator
Changes the background colour interactively.

### 03. Love Calculator
A fun application that calculates compatibility.

### 04. Income Tax Calculator
Calculates income tax based on user input.

### 05. Digital Clock
Displays the current time dynamically.

### 06. Countdown Timer
A countdown timer built using JavaScript.

### 07. Astrology Insight
An interactive astrology-related project.

### 08. Clicker
A simple clicking-based interactive project.

### 09. To Do List
Helps users organise and manage daily tasks.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Concepts Practised

- DOM Manipulation
- Event Handling
- Functions and Conditional Statements
- Working with Dates and Timers
- Dynamic Content Updates
- User Input Handling

## Getting Started

Clone the repository:

    git clone https://github.com/rohit9304850-lgtm/javascript-mini-projects.git

Open the repository folder, choose any project and open its `index.html` file in your browser.

You can also use Live Server in VS Code.
